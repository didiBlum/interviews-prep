## Recommended Preparation Order

### Phase 1: Coding Fundamentals (Week 1)

Start with the easier coding problems to build confidence and warm up.

1. **03 -- Reverse Lookup HashMap** (Medium, 30 min) -- Core data structures, good warm-up
2. **05 -- Tic Tac Toe** (Medium, 30 min) -- OOP design, game logic, clean code
3. **04 -- Notify Users/Teams** (Medium, 35 min) -- Graph traversal, real-world Monday.com scenario
4. **06 -- Number of Islands** (Medium, 25 min) -- Classic BFS/DFS, builds pattern recognition

### Phase 2: Coding Advanced (Week 1-2)

Tackle the harder problems that reflect actual interview difficulty.

5. **01 -- Web Crawler Site Map** (Medium-Hard, 45 min) -- Concurrency, graph traversal, system thinking
6. **02 -- Sort Large Table** (Medium-Hard, 45 min) -- External sort, scalability awareness, trade-offs

### Phase 3: System Design (Week 2-3)

Work through system design problems in order of complexity.

7. **SD 03 -- Event-Driven App Triggers** (Medium-Hard, 45 min) -- Start here; most approachable SD problem
8. **SD 01 -- Row Ordering in Board** (Hard, 45 min) -- Directly relevant to Monday.com's core product
9. **SD 02 -- Drag-Drop Multi-Client** (Hard, 45 min) -- Real-time sync, conflict resolution
10. **SD 04 -- Scalable Task Management** (Hard, 45 min) -- Full system design, capstone exercise

### Phase 4: Behavioral (Ongoing)

Behavioral prep can and should be done **in parallel** with the above phases.

- **Week 1:** Read through all questions, identify which stories from your experience map to each theme
- **Week 1-2:** Write out 6-8 STAR stories and practice speaking them aloud (aim for under 2 minutes each)
- **Week 2-3:** Do mock interviews with a friend or record yourself answering; refine based on feedback

## Tips

- **Time yourself** on every coding exercise. If you can't finish within the time limit, note where you got stuck and revisit.
- **For system design**, practice talking through your design out loud. The interviewer cares as much about your communication as your architecture.
- **For behavioral**, record yourself answering and play it back. Cut any answer that runs longer than 2 minutes.
- **Do at least one full mock interview** (coding + system design + behavioral) before the real thing.
