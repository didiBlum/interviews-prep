# Interview Prep Plan: Microsoft Senior Backend Engineer

## Overview
- **Total estimated prep time:** ~60-70 hours
- **Recommended timeline:** 3-4 weeks (15-20 hours/week)
- **Priority order:** Coding fundamentals → System Design → Behavioral → Company research
- **Key insight:** Behavioral is assessed in EVERY round at Microsoft — practice weaving STAR stories into coding/design discussions

## Week-by-Week Plan

## Readiness Checklist

### Coding
- [ ] Can solve all 8 coding exercises within time limit (45 min each)
- [ ] Comfortable with arrays, trees, graphs, DP, linked lists patterns
- [ ] Can implement LRU Cache from scratch in under 20 minutes
- [ ] Can explain time/space complexity for all solutions
- [ ] Practiced on Codility-like environment (no autocomplete)

### System Design
- [ ] Can articulate architecture for each of the 5 SD questions in 45 minutes
- [ ] Know Azure services: Cosmos DB, Service Bus, Event Hubs, AKS, Blob Storage
- [ ] Can discuss compliance, auditing, and data sovereignty requirements
- [ ] Practiced drawing diagrams on Excalidraw or whiteboard
- [ ] Can estimate capacity and make scaling calculations

### Behavioral
- [ ] Have 5+ STAR stories covering: ownership, failure, conflict, mentoring, ambiguity, cross-team influence
- [ ] Can answer "Why Microsoft?" authentically with specific product/team/mission references
- [ ] Can weave behavioral answers naturally into coding/design discussion
- [ ] Practiced delivery (2 min per story, concise, positive framing)
- [ ] Prepared thoughtful questions to ask interviewers

### Company Knowledge
- [ ] Understand Microsoft's growth mindset culture
- [ ] Read 3+ Engineering@Microsoft blog posts
- [ ] Used Azure or Microsoft products and formed opinions
- [ ] Know current AI initiatives (Copilot, RAG, LLM serving)
- [ ] Understand microservices architecture patterns (.NET, DDD, CQRS)
- [ ] Can answer "What is your favorite Microsoft product, and how would you improve it?"
