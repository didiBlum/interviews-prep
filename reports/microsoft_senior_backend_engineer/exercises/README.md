## Recommended Order
1. **Start with coding exercises** — do 01 (LRU Cache) and 02 (Merge Intervals) first as warm-ups
2. **Progress to harder coding** — 03, 06, 08 are the most challenging
3. **Move to system design** — start with 01 (Distributed Cache) as it's most commonly asked
4. **Behavioral last** — can prep in parallel with other exercises
5. **Practice timed** — once comfortable, redo exercises under interview time pressure
